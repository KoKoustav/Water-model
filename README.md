## Water Quality Prediction Project

**Objective:**  
To ensure safe and sustainable water resource management by assessing water quality and predicting potability. 💧

---

## What I Achieved
- Developed a binary classification model to evaluate water quality using key attributes such as pH, hardness, solids, and turbidity. 🔍  
- Implemented hyperparameter tuning to optimize model performance, with **Random Forest** emerging as the most accurate algorithm. 🏆  
- Created interactive Streamlit web apps to present actionable insights and facilitate data-driven decision-making. 🌐  

---

## Technical Stack
- **Python**: Model construction, hyperparameter tuning, and data analysis. 🛠️  
- **Streamlit**: User-friendly web apps for visualizing and presenting results. 📊  

---

## Challenges
- **Data Imbalance:** Addressed class imbalance using SMOTE (Synthetic Minority Over-sampling Technique), improving model training and performance. ⚖️  
- **Hyperparameter Tuning:** Fine-tuned model parameters to enhance accuracy and robustness, achieving **79% accuracy**. 📈  

---

## Model Comparison
- **Random Forest (79%)** outperformed the other algorithms tested (e.g., logistic regression, SVM, decision tree), whose accuracies ranged between 68%–75%.  
- This demonstrates the strength of ensemble methods on this dataset.
